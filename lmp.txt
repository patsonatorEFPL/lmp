```java
public class SecurityConfig {
    
    @Autowired
    private UserDetailsService userDetailsService;
    
    @Bean
    public SecurityFilterChain filterChain(HttpSecurity http) throws Exception {
        http
            .authorizeHttpRequests(auth -> auth
                .requestMatchers("/", "/about", "/services", "/contact", "/register", "/login", "/css/**", "/js/**", "/images/**").permitAll()
                .requestMatchers("/admin/**").hasRole("ADMIN")
                .requestMatchers("/dashboard/**", "/profile/**", "/orders/**").hasRole("USER")
                .anyRequest().authenticated()
            )
            .formLogin(form -> form
                .loginPage("/login")
                .defaultSuccessUrl("/dashboard")
                .permitAll()
            )
            .logout(logout -> logout
                .logoutUrl("/logout")
                .logoutSuccessUrl("/")
                .permitAll()
            )
            .rememberMe(remember -> remember
                .tokenValiditySeconds(86400)
                .key("lmpSecretKey")
            )
            .csrf(csrf -> csrf.ignoringRequestMatchers("/webhook/**"));
        
        return http.build();
    }
    
    @Bean
    public PasswordEncoder passwordEncoder() {
        return new BCryptPasswordEncoder();
    }
}
```

### 2. Intégration Stripe avec Pattern Strategy

```java
public interface PaymentStrategy {
    PaymentTransaction processPayment(Order order, PaymentDto paymentDetails);
    PaymentTransaction refundPayment(PaymentTransaction transaction, BigDecimal amount);
}

// filepath: com/lmp/service/payment/StripePaymentStrategy.java
@Service
public class StripePaymentStrategy implements PaymentStrategy {
    
    @Value("${stripe.secret.key}")
    private String stripeSecretKey;
    
    @Override
    public PaymentTransaction processPayment(Order order, PaymentDto paymentDetails) {
        try {
            Stripe.apiKey = stripeSecretKey;
            
            Map<String, Object> params = new HashMap<>();
            params.put("amount", order.getTotalAmount().multiply(new BigDecimal("100")).intValue());
            params.put("currency", "cad");
            params.put("description", "LMP - Commande #" + order.getId());
            params.put("source", paymentDetails.getToken());
            
            Charge charge = Charge.create(params);
            
            PaymentTransaction transaction = new PaymentTransaction();
            transaction.setOrder(order);
            transaction.setAmount(order.getTotalAmount());
            transaction.setCurrency("CAD");
            transaction.setPaymentMethod(paymentDetails.getPaymentMethod());
            transaction.setPaymentProvider("STRIPE");
            transaction.setTransactionId(charge.getId());
            transaction.setStatus(PaymentStatus.COMPLETED);
            
            return transaction;
        } catch (StripeException e) {
            throw new PaymentFailedException("Échec du paiement Stripe: " + e.getMessage());
        }
    }
    
    @Override
    public PaymentTransaction refundPayment(PaymentTransaction transaction, BigDecimal amount) {
        // Implémentation du remboursement
        return transaction;
    }
}

// filepath: com/lmp/service/payment/PaymentServiceImpl.java
@Service
public class PaymentServiceImpl implements PaymentService {
    
    @Autowired
    private Map<String, PaymentStrategy> paymentStrategies;
    
    @Autowired
    private PaymentTransactionRepository paymentRepository;
    
    @Autowired
    private OrderService orderService;
    
    @Autowired
    private InvoiceService invoiceService;
    
    @Autowired
    private EmailService emailService;
    
    @Override
    public PaymentTransaction processPayment(Long orderId, PaymentDto paymentDetails) {
        Order order = orderService.getOrderById(orderId);
        
        // Sélectionner la stratégie de paiement
        PaymentStrategy strategy = paymentStrategies.get(paymentDetails.getProvider().toLowerCase() + "PaymentStrategy");
        if (strategy == null) {
            throw new UnsupportedOperationException("Méthode de paiement non supportée: " + paymentDetails.getProvider());
        }
        
        // Traiter le paiement
        PaymentTransaction transaction = strategy.processPayment(order, paymentDetails);
        paymentRepository.save(transaction);
        
        // Mettre à jour le statut de la commande
        orderService.updateOrderStatus(orderId, OrderStatus.IN_PROGRESS, "Paiement reçu");
        
        // Générer et envoyer la facture
        Invoice invoice = invoiceService.generateInvoice(order);
        emailService.sendInvoiceEmail(order.getUser().getEmail(), invoice);
        
        return transaction;
    }
}
```

```java
@Service
public class OrderServiceImpl implements OrderService {
    
    @Autowired
    private OrderRepository orderRepository;
    
    @Autowired
    private OrderItemRepository orderItemRepository;
    
    @Autowired
    private OrderStatusHistoryRepository statusHistoryRepository;
    
    @Autowired
    private EmailService emailService;
    
    @Override
    public Order createOrder(OrderDto orderDto, User user) {
        Order order = new Order();
        order.setUser(user);
        order.setTotalAmount(orderDto.getTotalAmount());
        order.setStatus(OrderStatus.PENDING);
        order.setCreatedAt(LocalDateTime.now());
        
        Order savedOrder = orderRepository.save(order);
        
        // Sauvegarder les items de la commande
        orderDto.getItems().forEach(itemDto -> {
            OrderItem item = new OrderItem();
            item.setOrder(savedOrder);
            item.setService(itemDto.getService());
            item.setQuantity(itemDto.getQuantity());
            item.setPrice(itemDto.getPrice());
            orderItemRepository.save(item);
        });
        
        // Enregistrer l'historique du statut
        OrderStatusHistory history = new OrderStatusHistory();
        history.setOrder(savedOrder);
        history.setStatus(OrderStatus.PENDING);
        history.setNotes("Commande créée");
        history.setCreatedBy(user);
        history.setCreatedAt(LocalDateTime.now());
        statusHistoryRepository.save(history);
        
        return savedOrder;
    }
    
    @Override
    public void updateOrderStatus(Long orderId, OrderStatus status, String notes) {
        Order order = orderRepository.findById(orderId)
                .orElseThrow(() -> new ResourceNotFoundException("Commande non trouvée avec ID: " + orderId));
        
        order.setStatus(status);
        order.setUpdatedAt(LocalDateTime.now());
        orderRepository.save(order);
        
        // Enregistrer l'historique du statut
        OrderStatusHistory history = new OrderStatusHistory();
        history.setOrder(order);
        history.setStatus(status);
        history.setNotes(notes);
        // Définir l'utilisateur administrateur qui a effectué la modification
        history.setCreatedAt(LocalDateTime.now());
        statusHistoryRepository.save(history);
        
        // Si la commande est marquée comme terminée, inviter l'utilisateur à laisser un avis
        if (status == OrderStatus.COMPLETED) {
            emailService.sendReviewInvitationEmail(order.getUser().getEmail(), order);
        }
    }
    
    @Override
    public List<Order> getOrdersByUser(User user) {
        return orderRepository.findByUserOrderByCreatedAtDesc(user);
    }
    
    @Override
    public List<OrderStatusHistory> getOrderStatusHistory(Long orderId) {
        return statusHistoryRepository.findByOrderIdOrderByCreatedAtDesc(orderId);
    }
}
```

```java
@Service
public class ReviewServiceImpl implements ReviewService {
    
    @Autowired
    private ReviewRepository reviewRepository;
    
    @Autowired
    private OrderRepository orderRepository;
    
    @Override
    public Review createReview(ReviewDto reviewDto, User user) {
        // Vérifier si l'utilisateur a commandé ce service et si la commande est terminée
        Order order = orderRepository.findById(reviewDto.getOrderId())
                .orElseThrow(() -> new ResourceNotFoundException("Commande non trouvée"));
        
        if (!order.getUser().getId().equals(user.getId())) {
            throw new AccessDeniedException("Vous n'êtes pas autorisé à évaluer cette commande");
        }
        
        if (order.getStatus() != OrderStatus.COMPLETED) {
            throw new IllegalStateException("Vous ne pouvez évaluer que les commandes terminées");
        }
        
        // Vérifier si un avis existe déjà
        if (reviewRepository.existsByUserAndOrder(user, order)) {
            throw new IllegalStateException("Vous avez déjà évalué cette commande");
        }
        
        Review review = new Review();
        review.setUser(user);
        review.setOrder(order);
        review.setRating(reviewDto.getRating());
        review.setComment(reviewDto.getComment());
        review.setAdminApproved(false);
        review.setFeatured(false);
        review.setCreatedAt(LocalDateTime.now());
        review.setExpiresAt(LocalDateTime.now().plusDays(30));
        
        return reviewRepository.save(review);
    }
    
    @Override
    public void approveReview(Long reviewId) {
        Review review = reviewRepository.findById(reviewId)
                .orElseThrow(() -> new ResourceNotFoundException("Avis non trouvé"));
        
        review.setAdminApproved(true);
        reviewRepository.save(review);
    }
    
    @Override
    public void setFeaturedReview(Long reviewId, boolean featured) {
        Review review = reviewRepository.findById(reviewId)
                .orElseThrow(() -> new ResourceNotFoundException("Avis non trouvé"));
        
        review.setFeatured(featured);
        reviewRepository.save(review);
    }
    
    @Override
    public List<Review> getFeaturedReviews() {
        return reviewRepository.findByFeaturedTrueAndAdminApprovedTrueAndExpiresAtAfter(LocalDateTime.now());
    }
    
    @Override
    @Scheduled(cron = "0 0 0 * * ?") // Exécuté tous les jours à minuit
    public void cleanupExpiredReviews() {
        reviewRepository.deleteByExpiresAtBefore(LocalDateTime.now());
    }
}
```

```java
@Service
public class PdfBoxInvoiceGenerator implements InvoiceGenerator {
    
    @Value("${invoice.template.path}")
    private String templatePath;
    
    @Value("${invoice.output.path}")
    private String outputPath;
    
    @Value("${company.logo.path}")
    private String logoPath;
    
    @Override
    public String generateInvoicePdf(Invoice invoice, Order order) {
        try {
            // Charger le document PDF template
            PDDocument document = new PDDocument();
            PDPage page = new PDPage(PDRectangle.A4);
            document.addPage(page);
            
            PDPageContentStream contentStream = new PDPageContentStream(document, page);
            
            // Ajouter le logo
            PDImageXObject logo = PDImageXObject.createFromFile(logoPath, document);
            contentStream.drawImage(logo, 50, 750, 100, 50);
            
            // Titre de la facture
            contentStream.beginText();
            contentStream.setFont(PDType1Font.HELVETICA_BOLD, 18);
            contentStream.newLineAtOffset(250, 750);
            contentStream.showText("FACTURE");
            contentStream.endText();
            
            // Numéro de facture et date
            contentStream.beginText();
            contentStream.setFont(PDType1Font.HELVETICA, 12);
            contentStream.newLineAtOffset(400, 720);
            contentStream.showText("Facture N°: " + invoice.getInvoiceNumber());
            contentStream.newLineAtOffset(0, -20);
            contentStream.showText("Date: " + invoice.getIssueDate().format(DateTimeFormatter.ofPattern("dd/MM/yyyy")));
            contentStream.endText();
            
            // Informations client
            User user = order.getUser();
            contentStream.beginText();
            contentStream.setFont(PDType1Font.HELVETICA_BOLD, 12);
            contentStream.newLineAtOffset(50, 680);
            contentStream.showText("FACTURER À:");
            contentStream.setFont(PDType1Font.HELVETICA, 12);
            contentStream.newLineAtOffset(0, -20);
            contentStream.showText(user.getFirstName() + " " + user.getLastName());
            contentStream.newLineAtOffset(0, -15);
            contentStream.showText(user.getCompanyName() != null ? user.getCompanyName() : "");
            contentStream.newLineAtOffset(0, -15);
            contentStream.showText(user.getAddress() != null ? user.getAddress() : "");
            contentStream.newLineAtOffset(0, -15);
            contentStream.showText((user.getPostalCode() != null ? user.getPostalCode() + " " : "") + 
                                   (user.getCity() != null ? user.getCity() : ""));
            contentStream.endText();
            
            // En-têtes du tableau
            float tableTopY = 550;
            float tableBottomY = 200;
            float tableWidth = 500;
            float tableX = 50;
            float rowHeight = 20;
            
            // Dessiner la ligne d'en-tête
            contentStream.setLineWidth(1f);
            contentStream.moveTo(tableX, tableTopY);
            contentStream.lineTo(tableX + tableWidth, tableTopY);
            contentStream.stroke();
            
            // Colonnes
            String[] headers = new String[]{"Service", "Description", "Prix", "Quantité", "Total"};
            float[] columnWidths = new float[]{150, 150, 70, 60, 70};
            
            contentStream.beginText();
            contentStream.setFont(PDType1Font.HELVETICA_BOLD, 10);
            contentStream.newLineAtOffset(tableX + 5, tableTopY - 15);
            contentStream.showText(headers[0]);
            contentStream.newLineAtOffset(columnWidths[0], 0);
            contentStream.showText(headers[1]);
            contentStream.newLineAtOffset(columnWidths[1], 0);
            contentStream.showText(headers[2]);
            contentStream.newLineAtOffset(columnWidths[2], 0);
            contentStream.showText(headers[3]);
            contentStream.newLineAtOffset(columnWidths[3], 0);
            contentStream.showText(headers[4]);
            contentStream.endText();
            
            // Ligne sous les en-têtes
            contentStream.moveTo(tableX, tableTopY - 20);
            contentStream.lineTo(tableX + tableWidth, tableTopY - 20);
            contentStream.stroke();
            
            // Contenu du tableau (items de la commande)
            float nextY = tableTopY - 40;
            contentStream.setFont(PDType1Font.HELVETICA, 10);
            
            for (OrderItem item : order.getItems()) {
                Service service = item.getService();
                
                contentStream.beginText();
                contentStream.newLineAtOffset(tableX + 5, nextY);
                contentStream.showText(service.getTitle());
                contentStream.newLineAtOffset(columnWidths[0], 0);
                
                // Limiter la longueur de la description
                String description = service.getDescription();
                if (description.length() > 50) {
                    description = description.substring(0, 47) + "...";
                }
                contentStream.showText(description);
                
                contentStream.newLineAtOffset(columnWidths[1], 0);
                contentStream.showText(service.getPrice().toString() + " $");
                contentStream.newLineAtOffset(columnWidths[2], 0);
                contentStream.showText(String.valueOf(item.getQuantity()));
                contentStream.newLineAtOffset(columnWidths[3], 0);
                contentStream.showText(item.getPrice().toString() + " $");
                contentStream.endText();
                
                nextY -= rowHeight;
            }
            
            // Ligne de séparation avant le total
            contentStream.moveTo(tableX, tableBottomY);
            contentStream.lineTo(tableX + tableWidth, tableBottomY);
            contentStream.stroke();
            
            // Total
            contentStream.beginText();
            contentStream.setFont(PDType1Font.HELVETICA_BOLD, 12);
            contentStream.newLineAtOffset(tableX + 330, tableBottomY - 30);
            contentStream.showText("Total:");
            contentStream.newLineAtOffset(100, 0);
            contentStream.showText(order.getTotalAmount().toString() + " $");
            contentStream.endText();
            
            // Pied de page
            contentStream.beginText();
            contentStream.setFont(PDType1Font.HELVETICA, 10);
            contentStream.newLineAtOffset(tableX, 100);
            contentStream.showText("Merci pour votre confiance!");
            contentStream.newLineAtOffset(0, -15);
            contentStream.showText("Pour toute question concernant cette facture, veuillez contacter: contact@lmp-digital.ca");
            contentStream.endText();
            
            contentStream.close();
            
            // Créer le chemin du fichier
            String fileName = "invoice_" + invoice.getInvoiceNumber() + ".pdf";
            String filePath = outputPath + File.separator + fileName;
            
            // Sauvegarder le document
            document.save(filePath);
            document.close();
            
            return filePath;
            
        } catch (IOException e) {
            throw new RuntimeException("Erreur lors de la génération du PDF: " + e.getMessage(), e);
        }
    }
}
```

```java
    @Value("${company.name}")
    private String companyName;
    
    @Override
    public void sendRegistrationEmail(String to, String name, String verificationUrl) {
        try {
            MimeMessage message = mailSender.createMimeMessage();
            MimeMessageHelper helper = new MimeMessageHelper(message, true, "UTF-8");
            
            helper.setFrom(new InternetAddress(fromEmail, companyName));
            helper.setTo(to);
            helper.setSubject("Bienvenue sur LMP - Confirmez votre inscription");
            
            Context context = new Context();
            context.setVariable("name", name);
            context.setVariable("verificationUrl", verificationUrl);
            context.setVariable("companyName", companyName);
            context.setVariable("currentYear", Year.now().getValue());
            
            String htmlContent = templateEngine.process("emails/registration", context);
            helper.setText(htmlContent, true);
            
            mailSender.send(message);
        } catch (Exception e) {
            throw new RuntimeException("Erreur lors de l'envoi de l'email: " + e.getMessage(), e);
        }
    }
    
    @Override
    public void sendInvoiceEmail(String to, Invoice invoice) {
        try {
            MimeMessage message = mailSender.createMimeMessage();
            MimeMessageHelper helper = new MimeMessageHelper(message, true, "UTF-8");
            
            helper.setFrom(new InternetAddress(fromEmail, companyName));
            helper.setTo(to);
            helper.setSubject("Votre facture LMP #" + invoice.getInvoiceNumber());
            
            Context context = new Context();
            context.setVariable("invoiceNumber", invoice.getInvoiceNumber());
            context.setVariable("issueDate", invoice.getIssueDate().format(DateTimeFormatter.ofPattern("dd/MM/yyyy")));
            context.setVariable("order", invoice.getOrder());
            context.setVariable("companyName", companyName);
            context.setVariable("currentYear", Year.now().getValue());
            
            String htmlContent = templateEngine.process("emails/invoice", context);
            helper.setText(htmlContent, true);
            
            // Ajouter la facture en pièce jointe
            FileSystemResource file = new FileSystemResource(new File(invoice.getPdfPath()));
            helper.addAttachment("Facture_" + invoice.getInvoiceNumber() + ".pdf", file);
            
            mailSender.send(message);
            
            // Marquer la facture comme envoyée
            invoice.setSent(true);
        } catch (Exception e) {
            throw new RuntimeException("Erreur lors de l'envoi de l'email avec facture: " + e.getMessage(), e);
        }
    }
```

## Mise en œuvre technique

1. **Base de données MySQL**
   - Configurez les propriétés dans `application.properties` ou `application.yml`
   - Utilisez Flyway ou Liquibase pour les migrations de base de données

2. **Intégration Stripe**
   - Créez un compte Stripe et obtenez vos clés API
   - Configurez les webhooks pour les notifications de paiement

3. **Sécurité**
   - Utilisez Spring Security pour l'authentification et l'autorisation
   - Implémentez des tokens JWT pour l'API si nécessaire

4. **Documentation API**
   - Utilisez Springdoc-OpenAPI pour la documentation automatique des endpoints

5. **Tests**
   - Écrivez des tests unitaires pour les services
   - Créez des tests d'intégration pour les contrôleurs et repositories
   - Utilisez Mockito pour mocker les dépendances

## Points d'attention

1. **Soft Delete pour les utilisateurs**
   - Ne supprimez jamais réellement les utilisateurs
   - Mettez à jour leur statut à "DELETED" et anonymisez certaines informations personnelles

2. **Journalisation**
   - Configurez SLF4J avec Logback pour une journalisation efficace
   - Assurez-vous de journaliser toutes les opérations critiques

3. **Gestion des erreurs**
   - Créez un gestionnaire d'exceptions global pour une expérience utilisateur cohérente
   - Envoyez des notifications pour les erreurs critiques

4. **Performance**
   - Utilisez le cache pour les données fréquemment accédées
   - Optimisez les requêtes SQL avec des index appropriés

5. **Meilleures pratiques de sécurité**
   - Protection CSRF
   - Validation des entrées
   - Protection contre l'injection SQL
